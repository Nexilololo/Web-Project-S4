# EFREI Computer Science Department - Web Project

This website was developed as part of the **TI402 - Web Programming** module at EFREI. The project aims to provide a modern, professional, and responsive platform to showcase the academic programs, faculty members, and research initiatives of the Computer Science department.

## Team Members
- **Antonin Autret**
- **Charles Guégan**

## Key Features
- **Modern Homepage**: Includes a custom hero banner with diagonal design and an interactive image carousel.
- **Academic Showcase**: Dedicated pages for undergraduate and graduate programs.
- **Faculty Directory**: Integrated list of teaching staff and researchers.
- **Research & Innovation**: Showcase of the department's latest research areas and student projects.
- **Responsive Experience**: The layout is fully optimized for mobile, tablet, and desktop viewing.

## Technical Specifications
- **HTML5**: Semantic structure to ensure accessibility and SEO best practices.
- **CSS3**: Advanced styling using Flexbox, CSS Grid, and custom `clip-path` for visual transitions.
- **JavaScript**: Custom implementation for the image slider (auto-slide and manual control) and dynamic navigation state management.

## Getting Started
To view the project locally, clone the repository and open the following file in any modern web browser:
`html/home.html`
